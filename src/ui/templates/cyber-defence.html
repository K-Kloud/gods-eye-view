Trace observed transfers

Trace time-ordered connections in supplied public blockchain records or authorised ledger extracts. Verify ownership, the source of funds and any suspected illicit activity independently.

Use one ledger and asset per run. Paste up to 300 rows without a header. Each row has a unique reference, ISO UTC time, sender, recipient, amount and source, separated by tabs. Use aliases for private accounts.

Use a transaction hash plus a transfer index when one transaction contains several transfers. Identifiers are case-sensitive. Input is processed in this page and cleared on reload.
